# ティッカー USD の日足検証

対象は通貨ではなく、TradingView の **AMEX:USD / ProShares Ultra Semiconductors** です。半導体指数の**日次**リターンの2倍を目標とするETFです。

2026-10-01に取得した Yahoo Finance の日足 OHLCV（2007-02-01〜2026-09-30、4,947本）を使い、`backtest_daily.py` で売買と約定を概算再現しました。価格・出来高フィルターにより、2007〜2015年の完了取引は0回です。

## TradingView の検証結果

2026-10-01、ログインした TradingView の **AMEX:USD・日足**チャートに現在の Pine v6 ストラテジーを追加し、Deep Backtesting の全期間（2007-02-01〜2026-10-01）で再計算しました。Pine エディタのコンパイルエラーはなく、ストラテジーレポートは **30取引・25勝・勝率83.33%・純損益+$8,930.20・プロフィットファクター2.461・最大ドローダウン$3,166.40（3.06%）** でした。初期資金$100,000、建玉10%、手数料0.05%、スリッページ1ティックをスクリプトで設定しています。

以下の表は別データ源を使った Python の**概算**です。TradingView と取引数・勝敗は一致しましたが、価格データと約定計算の違いにより損益額は一致しません。成績の判断には上記の TradingView の数値を優先してください。

現在設定の30取引は勝ち25回・負け5回で、平均利益約$634、平均損失約$1,229、最大の単一取引損失約$2,238です。平均損失は平均利益の約1.9倍です。30取引の観測勝率83.3%は将来の勝率が80%超である証拠にはならず、単純な二項比率の95% Wilson区間は約66.4〜92.7%です。

約定コストに敏感です。1株・1約定あたりの想定スリッページを$0.02にすると30取引・勝率80.0%・純損益+$7,965.88、$0.05にすると30取引・勝率63.3%・純損益+$2,891.12になります。過去の分割調整後の低価格期では固定金額のスリッページが価格に対して大きいため、これらは感度試験であり実際の約定コストの推定値ではありません。

現在設定は過去データ上で複数の候補を比較して選びました。閾値を少し変えると、RSI 5・1ATRでは27取引・勝率81.5%、RSI 7・1ATRでは30取引・勝率80.0%、押し目0.75ATR・RSI 5では29取引・勝率79.3%でした。2024年以降の結果も開発中に参照しているため、独立した未見データによる検証ではありません。過剰適合の可能性があります。

**判定:** TradingView の過去データでも観測勝率は80%を超えました。リアルタイムでの検証は未実施です。レバレッジETFの急落やギャップでは、想定ストップより不利な価格で約定し得ます。勝率や利益を保証するものではありません。
