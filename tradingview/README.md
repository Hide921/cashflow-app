# 米国株・ETF日足の売買アラート

`us-stocks-daily-pullback.pine` は、上昇トレンド中の短期的な押し目で買い、反発・トレンド崩れ・保有日数・ATRストップで売る、買いポジション専用の Pine Script v6 ストラテジーです。銘柄を指定せず使えますが、勝率や利益を保証するものではありません。

ティッカー **USD**（ProShares Ultra Semiconductors）には `usd-daily-pullback.pine` を使ってください。USD向けの価格・出来高条件、RSI(2) 閾値6、20日EMAから1ATR以上の押し目を初期設定し、USDの日足以外では買いシグナルを出しません。TradingView の全期間バックテストでは30取引・勝率83.33%でしたが、将来の成績ではありません。条件とリスクは `USD_BACKTEST.md` で確認してください。

## TradingView で使う

1. 対象の米国株またはETFのチャートを開き、時間足を **1D**、セッションを **通常取引時間** にする。USD向けには TradingView の **AMEX:USD** を選ぶ。
2. Pine エディタに `.pine` ファイルの内容を貼り付け、保存してチャートに追加する。
3. **Strategy Tester** で対象銘柄の取引数、勝率、プロフィットファクター、最大ドローダウン、手数料込みの純損益を確認する。取引数が少ない場合は勝率を信用しすぎない。期間を分けて検証する。
4. アラート作成画面で条件にこのストラテジーを選び、**Order fills only** を選択する。メッセージ欄には初期設定の `{{strategy.order.alert_message}} | fill={{strategy.order.price}}` を使用する。

買い・通常の売り注文は日足確定時に生成され、標準設定では次の取引日の始値以降に約定通知が出ます。ストップ注文は取引時間中に約定通知が出ることがあります。翌日のギャップや実際の約定価格はバックテストと異なり得ます。アラートは取引注文そのものではありません。

パラメータやコードを変えた後は、TradingView 上の既存アラートを削除して作り直してください。アラートは作成時点のストラテジー設定を保持します。

NVDAでの概算検証結果は `NVDA_BACKTEST.md` を参照してください。
